# Challenge Encriptador de Texto

## 📖 Descripción del Proyecto
Este repositorio contiene la resolución del Challenge "Encriptador de Texto". Consiste en una aplicación web interactiva que permite encriptar y desencriptar mensajes secretos utilizando un conjunto específico de llaves de conversión.

Este fue el primer reto de la formación Oracle Next Education (ONE) en colaboración con Alura LATAM, y su objetivo principal es poner en práctica los fundamentos del desarrollo Frontend, la manipulación del DOM (Document Object Model) y la lógica de programación básica.

## 📚 Historia y Contexto
El desafío consistió en construir una interfaz gráfica donde el usuario pudiera ingresar un texto y transformarlo según unas reglas de encriptación específicas (por ejemplo, la letra "a" se convierte en "ai", la "e" en "enter", etc.). 

El reto principal técnico fue aprender a conectar la estructura visual (HTML/CSS) con el comportamiento dinámico (JavaScript), capturando los eventos de los botones, validando que el texto ingresado cumpliera con los requisitos (solo minúsculas y sin acentos), y actualizando la pantalla con el resultado final.

## 🔨 Funcionalidades

La aplicación cuenta con una interfaz intuitiva que permite:
* **Funcionalidad 1:** Encriptar un texto ingresado por el usuario basándose en las llaves de encriptación predefinidas.
* **Funcionalidad 2:** Desencriptar un texto previamente oculto para devolverlo a su estado original.
* **Funcionalidad 3:** Validar los datos de entrada, asegurando que solo se procesen letras minúsculas, sin acentos ni caracteres especiales.
* **Funcionalidad 4:** Copiar fácilmente el texto resultante (encriptado o desencriptado) al portapapeles mediante un botón dedicado.
* **Funcionalidad 5:** Interfaz responsiva que se adapta correctamente a dispositivos móviles, tablets y computadoras de escritorio.

## 🛠️ Tecnologías utilizadas
